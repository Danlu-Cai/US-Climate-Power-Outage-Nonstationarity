# Climate–Power Outage Relationships Across the United States

**Author:** Danlu Cai  
**Institution:** The University of Alabama in Huntsville (UAH)

## Overview

This repository contains R scripts supporting research on the spatial and temporal variability of climate–power outage relationships across the contiguous United States (CONUS).

The study examines high-impact power outages, the predictive contributions of climate and environmental factors, temporal changes in model performance, and nonlinear climate-response relationships.

The analyses integrate EAGLE-I power outage observations, CONUS404 climate data, and machine-learning methods including XGBoost and Random Forest.

## Study Period

- Power outage trend analysis: 2015–2024.
- Climate–outage machine-learning analyses: 2015–2022.
- Historical comparison period: 2015–2018.
- Recent comparison period: 2019–2022.

## Data Sources

**EAGLE-I:** County-level electricity outage observations used to characterize high-impact power outage patterns.

**CONUS404:** High-resolution meteorological data used to derive temperature-related climate indicators and extreme-event metrics.

Additional environmental and geographic variables are included in the merged analysis datasets.

## Analysis Workflow

1. Process EAGLE-I power outage observations and identify high-impact outages.
2. Process CONUS404 temperature data to calculate heating and cooling degree days.
3. Identify extreme heat and cold events.
4. Integrate outage, climate, and geographic datasets.
5. Evaluate climate–outage relationships using Random Forest and XGBoost.
6. Analyze temporal nonstationarity and nonlinear climate-response relationships.
7. Generate the manuscript figures.

See [code/README.md](code/README.md) and [figures/README.md](figures/README.md) for script-level documentation.

## Reproducibility

The scripts use configurable input and output directories. Users must obtain the required datasets and configure their local paths before execution.

Some figure scripts depend on intermediate datasets or CSV files generated by earlier analyses.

Model-based feature importance, incremental predictive performance, and accumulated local effects describe predictive associations and should not be interpreted as evidence of causality.

## Data Availability

Availability of underlying datasets and processed analysis files is subject to their respective access and redistribution conditions. The repository provides analysis code and documentation for reproducing the workflow with the required data.
